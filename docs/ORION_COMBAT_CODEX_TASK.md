## 2. Святилище: бой отдельно от сцены
Прямое решение автора для Святилища в целом: после активации реликвии сцена сохраняется, пока реликвия лежит на алтаре. После победы Поле Боя и слёзницы остаются, игроки могут ходить по арене, уйти и вернуться. Никакого автоматического сброса по таймеру, победе, поражению, STOP, уходу игроков или рестарту. Нейтральная сцена только после ручного фактического изъятия реликвии. Аварийная операторская диагностика — не штатный игровой путь.
Текущий PantheonCombat.tick WON/FAILED → beginCleanup→NEUTRAL, recover аналогично; PantheonAltar.editable требует neutralReady. Разделить жизненный цикл и проверки activeCombat/sceneOwned/canExtract/canInsert/canStart/canStop/holdsGate. Адаптировать PantheonCombat, PantheonCombatJournal, PantheonArena, PantheonAltar/Menu/Screen, PantheonTrial, PantheonEditor и защитные хуки, не создавать параллельную систему.
- NEUTRAL: установка реликвии не запускает бой сама; START готовит её сцену.
- PREPARING → OPEN → FIGHT: Орион уже стоит на готовой арене в idle, пассивен и неуязвим до начала. Существующие окна набора 10 с после первого вошедшего, пустой тайм-аут 120 с, ограничения участников, зрителей, PvP, выхода ключом, сохранение инвентаря/XP и возврат выбывших сохраняются. Слот заблокирован.
- FINALE/DYING: проиграть полную смерть, вспышку и цветение; не атакует и не получает повторного летального результата.
- RETAINED_WON/FAILED/STOPPED: закончить бой, удалить только его сущности/снаряды, снять bossbar и combat tickets, открыть ворота, не выгонять победителей. Сохранить декор, цветение только при победе. Слот доступен для изъятия. STOP владельца/OP во время боя безопасно завершает сессию, но не очищает сцену. Рабочий технический выбор: для нового запуска сначала вынуть реликвию, дождаться reset, поставить снова; START не перезаписывает цветущую сцену. Не менять права владельца отмены. Обычный игрок после завершения может извлечь реликвию согласно общему характеру алтаря.
- RESETTING: только после успешного ручного изъятия на сервере. Закрыть/эвакуировать перестраиваемую область штатно, заблокировать вставку до завершения, затем открыть ворота. При ошибке диагностика и повтор восстановления, не выдавать дубликат и не стирать чужие блоки.
- Один канонический слот и chunk attachment; раздельные серверные predicates для вставки/изъятия. Атомарная операция с журналом намерения/завершения, защита от двух окон, shift-click, swap, полного инвентаря, смерти с курсором и повторных пакетов. Не подменять занятую реликвию одним swap в retained: извлечение, reset, затем вставка. Клиентский клик не доказательство изъятия.
- Персистентность: хранить ID сцены/реликвии/плана, retained outcome, цветение, ID сессии и факт завершения. После рестарта победная сцена и слёзницы остаются, ворота открыты, награда не повторяется. Прерванный активный бой не возобновлять; при сохранённой реликвии перевести в retained_failed, а не сбрасывать сцену. Прерванный reset при пустом алтаре продолжить. Для finale определить идемпотентную границу победы/цветения. Миграция v1 журналов и старых миров без потери предметов. Не стирать авторский edited baseline. Редактор недоступен при удержанной сцене. При несогласованности fail-closed с диагностикой, не автоматический reset удержанной арены.
- Обычный возврат победителей в хаб добровольный. Гибель всей группы в тот же тик, что и летальный удар по цели, остаётся поражением, как сейчас.

## 5. ИИ и цепочки
Серверный автомат одной техники и активной цепочки. Секущая серия — фактические удары авторского клипа и дуги меча. Рывок с прокрутом — поражение по пройденной траектории, не гарантированный hit/телепорт. Разрубание — тяжёлый двуручный удар и локальная волна в точке падения клинка. Додж — уклонение и маневрирование/смена угла, проверка свободного направления, не автоматически i-frames и не реакция на каждый удар. Орион быстрый, не ходит постоянно за игроком по прямой.
Угроза только среди живых участников FIGHT, учитывать расстояние, достижимость, недавний урон и время без попадания, видимость. Рывок на дальнего либо опасного недостижимого игрока, но не делать любой дальний бой бессмысленным. Перевыбор цели на разумной границе шага, не сверхчеловеческое слежение в момент удара; без ударов по зрителям/выбывшим/NPC. Доджи для реакций и позиционных решений. Проверять стену, не застревать.
С = секущая серия; Р = круговой рывок; Т = разрубание; Д = додж.
| Паттерн | Цепочка | Фаза | Рабочая мотивация |
|---|---|---|---|
| Базовое комбо | С → Р | 1/2 | обычное ближнее давление |
| Мощный напор | Р → Т | 1/2 | сближение и тяжёлый удар |
| Полное комбо | С → Р → Т | 1/2 | продолжение давления |
| Быстрая серия | Д → Р → Д → Р → С | 1/2 | мобильная цель, смена позиции |
| Смертельное комбо | Р → Т → Р → Т → Р → Т | 2 | редкая тяжёлая серия |
| Стремительный натиск | Р → Р → Р → Р | 2 | преследование |
Порядок обязателен, новые паттерны не добавлять. КД индивидуальной техники ограничивает выбор новой цепочки, но не преднамеренные повторения уже запущенной. Отдельный бюджет/КД длинных цепочек и обязательные окна ответа после них. Не начинать две серии одновременно, не повторять бесконечно, не создавать неотвечаемые комбинации. При потере цели, препятствии, STOP, усилении/смерти корректно отменять или завершать шаг в безопасной границе. Одиночная техника по ситуации допустима как рабочий ИИ-вариант, не замена шести цепочек. Диагностировать шаги, цели, причины выбора и отмены.

## 6. Фазы и баланс
Усиление один раз при пороге HP, на весь каст неуязвимость; не допускать пропуска фазы burst-уроном. Вход в корректной границе текущего движения, без зависания до конца длинной цепочки. После 2,5-секундного авторского клипа снимается иммунитет, активируется phase2, максимальная аура и комбо 5/6. После усиления выше урон и скорость, меньше КД всех техник, к AoE добавляется световой взрыв. При касте разрубания умеренная защита от входящего урона, не иммунитет; привязать к реальному интервалу каста. Додж не неуязвимость по умолчанию. Не стэковать редукции/множители дважды.
Одобренные стартовые ориентиры, не окончательные статы: HP 400–600 соло (технический ориентир, не утверждённое фиксированное HP), порог 50% как обратимый рабочий выбор; phase1 согласованный baseline, phase2 playback ×1,25–1,35, движение ×1,30, КД ×0,65–0,75, урон ×1,15–1,25, cleave incoming ×0,75. Не ускорять empower/death фазовым множителем. Подобрать конкретные числа, вынести компактно в настройку: HP, броня/отброс, шаг, hit/радиусы/дистанция/скорость, cooldown/recovery, комбо веса, threat, световые взрывы, scaling по фиксированному числу участников. Не динамически лечить при выбывании. Не превращать 5с cleave или длинные phase2 цепочки в мешок HP/безответный спам. Проверить реальные окна и урон всей серии. Не придумывать иммунитет к Чернилам по лору. Оба Пути должны иметь возможность ответить: уклонения/контратаки и блоки/идеальные блоки/Резонансы; проверять существующее парирование и дальние способности. Не менять глобальные оружие/щиты/обеты/других мобов ради босса. Баланс по фактическим тестам, отдельно указать неподтверждённые цифры.
