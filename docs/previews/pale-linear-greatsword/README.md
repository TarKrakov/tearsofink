# Бледный линейный двуручник — предпросмотры

Сгенерированы существующим `tools/preview` по игровым JSON и авторской объёмной геометрии. В каждом кадре: **сзади (F5), спереди, от первого лица**.

| Движение | GIF |
| --- | --- |
| Четыре одиночных удара | [Одиночная серия](solo.gif) |
| Три парных удара, отдельная левая рука | [Парная серия](pair.gif) |
| Прерывание третьего удара → R → колющий рывок | [Одиночный R](solo-r.gif) |
| Удержание ПКМ → пронзающий рывок | [Парный ПКМ](pair-charge.gif) |
| Парирование → разведение мечей → прыжок → разруб | [Парный R](pair-r.gif) |

Листы кадров: [одиночный](solo.png), [парный](pair.png).

Это технический рендер: цвет различает руки, авторская текстура не заменена. Перемещение сущности, враги, разрушение блоков и урон проверяются на сервере, а не симулируются этим просмотрщиком. Прыжок здесь показан позой оружия на неподвижном манекене.

Воспроизведение и все дополнительные GIF (семь отдельных ударов, четыре прерывания R и левая способность):

```sh
python3 tools/preview/check_pale.py
python3 tools/preview/pale.py out/pale
```

Зависимости просмотрщика прежние: NumPy, Pillow, шрифт DejaVu Sans Mono. Смешивание в `tl.py` повторяет 0,12 секунды `ease_out` из `WeaponAnims` и `ThirdPerson`, включая повторное прерывание во время перехода.
