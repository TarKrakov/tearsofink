# Бледный меч — небольшая доводка принятой серии

17 ноября 2026. Принятые ЛКМ из `09f8688` сохранены. По новой просьбе добавлены одиночный ПКМ с разрубом/отскоком, отдельный урон фаз одиночного R, подъём рук в парном прыжке **только на R** и небольшой вынос спокойной стойки вперёд. [Поведение, числа, серверные проверки и границы](../../PALE_MOVE_BALANCE.md). Нужен **новый JAR и перезапуск Minecraft**.

Автору понравилась база `09f8688`; художественная оценка новых дополнений ещё ожидается. [Сохранённые уроки](../../ANIMATION_LESSONS_PALE_2026-11-17.md).

Крупные **FP 960×540, 16:9, 30 FPS**, с прицелом и ориентиром HUD:

- **[Одиночная серия — FP](solo-fp.gif)**: диагональ → верхний разруб → прямой укол. [Основные кадры](solo-fp.png), [кадры перехода 1→2](solo-bridges.png).
- **[Парная серия — FP](pair-fp.gif)**: сохранённые удары с согласованными клинками и новым началом повторного разруба. [Основные кадры](pair-fp.png), [кадры перехода 3→4](pair-bridges.png).
- **[Общие атаки 3/4 — FP](pair-3-4-fp.gif)**.

F5 изменён только у подготовки прыжка R и входа приземления (4 клипа с учётом левой руки). Остальные 27 снимков источников/поправок/времён, включая парные повторы ЛКМ, совпадают с прежней базой. [Спокойная стойка](baseline.png) теперь на 0.04 блока дальше камеры в обоих хватах, с плавным входом/выходом; боевая посадка, модель, текстура, исходник и масштаб прежние.

Цвет различает руки; авторская текстура и физика сущности здесь не симулируются. Кадры стыков извлечены из полных FP-GIF. Выполнены тесты локального dedicated-сервера с сетевым клиентом; графический Minecraft-клиент не запускался. Новые движения ещё требуют оценки автора в игре.
