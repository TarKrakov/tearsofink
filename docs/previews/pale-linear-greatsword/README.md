# Бледный меч — небольшая доводка принятой серии

17 ноября 2026. Принятая автором база `ee55b6e`: сохранена постановка ударов, добавлены короткие связки, FP немного ниже и ближе. По следующей просьбе автора мечи дополнительно приближены ещё на 0.10 блока в обоих хватах; текущий суммарный сдвиг — 0.04 вниз / 0.15 к камере. [Что изменилось и как проверено](../../PALE_FLOW_POLISH_2026-11-17.md). Для игры нужен **новый JAR и перезапуск Minecraft**: добавлена поддержка общего FP-сдвига в Java.

[Нейтраль](baseline.png), авторские модель/исходник/текстура/масштаб прежние. Общий FP-сдвиг применяется и в нейтрали; на выходе из удара посадка не скачет.
