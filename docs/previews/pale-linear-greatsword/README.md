Это технический рендер реальной авторской геометрии: цвет различает руки; материал/текстура и физика прыжка манекена не симулируются. Результат ещё требует оценки автором в Minecraft.

Воспроизведение из корня репозитория:

```sh
python3 tools/preview/check_pale.py
python3 tools/preview/review.py pale_linear_greatsword --check-only
python3 tools/preview/review.py pale_linear_greatsword --render --fps 30
python3 tools/preview/pale.py out/pale
```
