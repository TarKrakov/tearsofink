# JABER 1.0.0 — техническая обратная связь автору мода

Проверен предоставленный chaos_duck_jaber-1.0.0.jar (SHA-256 eafebaf90836b07d353a4adcab61fa4a2a29c25da4fc6d869efb490bf3f6964b) через javap -p -c -l -s. Это статический разбор, не профилирование и не воспроизведение логов. Minecraft 1.21.1, Fabric Loader >=0.20.1, Java >=21, Fabric API. В моде используется ванильная Frog, предмет frog_call, метка jaber_owner_<UUID>, команда /jaber x z, собственный поиск пути, плавание/всплытие, реплики, случайные объезды и высадки.

У Tears of Ink собственный шумный конечный край с петлёй и пять магистралей, в том числе мосты с намеренными разрушениями. Это не ошибка JABER само по себе. Желательный интерфейс расширения: допуск цели и колонок по измерению, цена блока/сегмента, предпочтительные waypoint, безопасное отключение случайных аварийных поведений. У нас уже есть необязательный отдельный маршрутизатор, исходный JAR не изменяется. Точная причина первоначальных 100+ ошибок остаётся неизвестна: нужен latest.log с первым stack trace, координатами, действием; рекомендуются проверки обычного мира/кастомного измерения, двух пассажиров/владельцев, смены измерения, перезапуска, длинной поездки и разрушенного моста.
