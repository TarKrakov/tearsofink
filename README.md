# Tears of Ink

**Tears of Ink** — авторский мод-приключение для **Minecraft 1.21.1** на **Fabric** (код рассчитан на **Java 21**). Проект находится в активной разработке; художественные ресурсы, баланс и игровые системы изменяются по решениям автора.

## С чего начать

- [Опорная карта проекта](docs/PROJECT_COMPASS.md) — концепция, границы и действующие договорённости.
- [Журнал решений](docs/DECISIONS.md) — утверждённые решения и их статус.
- [Техническая карта](docs/PROJECT_STATUS.md) — состояние реализованных систем и ограничений проверки.
- [Правила работы с репозиторием](AGENTS.md) — безопасность художественных ресурсов, совместимость и процесс внесения изменений.

**Исторические документы не всегда описывают актуальное поведение**: при расхождениях проверяйте действующий код и последние решения. Рабочие файлы проекта, тестовые сцены и авторский арт не следует удалять только по имени «test», «placeholder» или «old».

## Где что лежит

| Путь | Назначение |
| --- | --- |
| `src/main/java`, `src/client/java` | Общая/серверная и клиентская реализация Fabric |
| `src/main/resources` | Игровые JSON, модели, текстуры, локализация, datapack-ресурсы |
| `blockbench/` | Авторские исходники моделей и редакторские сцены |
| `tools/blockbench/` | Сцена постановки анимаций оружия, помощник Blockbench, импортёр и его тесты |
| `tools/preview/` | Математические проверки, контрольные рендеры и вспомогательные инструменты для анимаций |
| `docs/previews/` | Сохранённые визуальные сравнения и отчёты: история принятия решений, а не мусор сборки |
| `docs/` | Проектная документация, баланс, технические решения и история проверок |
| `.github/workflows/` | Автоматические сборки и проверки |

Инструкция по анимациям: [Blockbench → Tears of Ink](tools/blockbench/README.md). Сохранённая тестовая сцена редактора: [`blockbench/toi_animation_test.bbmodel`](blockbench/toi_animation_test.bbmodel).

## Сборка

Используйте Gradle Wrapper:

```bash
./gradlew build
```

Цель компиляции мода — Java 21. В GitHub Actions сборка запускается на JDK 25 с выпуском Java-21 байткода. Успешная сборка и автоматические проверки **не заменяют** игровой тест в Minecraft, особенно для камер, анимаций и мультиплеера.
