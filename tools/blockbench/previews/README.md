# Проверки Blockbench → Tears of Ink, 17.11.2026

**Реальные скриншоты Blockbench 5.2.2 + Cameras 1.2.2:**

- [FP: свободный редактор слева, закреплённый кадр справа](blockbench_fp.png).
- [После вращения свободной камеры — правый кадр не меняется](blockbench_fp_orbit.png).
- [F5: непрозрачный манекен, два меча, демонстрационный timeline](blockbench_f5.png).

Это скриншоты приложения, не Python-рендеры. Голова, корпус, ноги, руки непрозрачны. Проверены переключения FP/F5 front/back и ручное создание ключей мышью на руке и sword bone. Схематичные руки — технические направляющие.

**Обратный предпросмотр экспортированных клипов через существующий `tools/preview`:**

- [Один меч: три ракурса](single.gif), [FP 960×540](single_fp.gif).
- [Два меча: три ракурса](dual.gif), [FP 960×540](dual_fp.gif).
- [Отдельный импорт demo — новые bb_test_guard клипы](demo_import.json).

Рендер Claude рисует мечи условными цветами по рукам, не авторским PNG. На скриншотах Blockbench показана настоящая встроенная текстура. Низкая поза demo — пример вращения костей, не новая согласованная боевая постановка.

Воспроизведение из корня репозитория:

```bash
python tools/blockbench/import_weapon_animation.py tools/blockbench/pale_animation_workspace.bbmodel \
  --clip animation.toi.demo_dual_guard --output work/blockbench/demo.json
python tools/blockbench/preview_import.py work/blockbench/demo.json --output work/blockbench/preview
```

Матричные тесты: обе demo, 121 момент на клип и обе руки, отдельное движение FP-руки и F5-кисти, независимые Display. На отсчётах bake допуск 1e-7 блока/элемента матрицы; между отсчётами 60 FPS — 3e-4 (для положения это 0.0048 пикселя модели). Это тест математики, **не измеренная погрешность в кадре Minecraft**.

Живая сверка с Minecraft не выполнена. Сохранённую из веб-редактора копию среда не предоставила для повторного открытия; эта часть round-trip ещё требует проверки. Подробности и ограничения — [инструкция](../README.md).
