# Каменный фонарь — авторский резерв

По прямому решению автора (D-106) каменный фонарь выведен из доступного контента мода.

- В этой папке сохранены **оригинальные** Blockbench-модель, экспортированная игровая модель, текстура и старый рецепт. Файлы не входят в JAR.
- В игре остаётся техническая регистрация `tears-of-ink:stone_lantern` только для чтения существующих миров и прежних предметов. Старые установленные фонари отображаются как Чернильные с прежним двухблочным коллизионным каркасом. Модель автора из игры изъята.
- Новые каменные фонари не выдаются вкладкой творческого инвентаря и не создаются крафтом.
- Сломанный ранее установленный каменный фонарь теперь даёт обычный Чернильный фонарь (только самодельные).
- Возвращать авторскую геометрию в мод только по новому решению автора.

Оригинальные байты сохранены через Git blobs без перекодирования.
